# 同屋 · 合租生活管家

公开站点：https://qiuyuemin.github.io/roommate/

原生 HTML、CSS、JavaScript，无构建依赖。GitHub Pages 从 main 分支根目录发布。

包括首页、费用均摊及结清记录、值日安排与轮换、库存消耗与补货提醒、公约编辑与认可。金额以整数分计算，余数按参与者顺序分配。

当前为产品体验版：四位示例室友，数据保存在当前浏览器 localStorage，未接入多人同步、支付或后台推送。切换室友用于体验不同视角，不代表身份认证。

旧版已从发布文件中移除，仍可从 Git 历史恢复。保持用户名、仓库名和 Pages 发布地址不变。

## 费用 AA

固定居住费用与其他个人费用分栏，按费用所属月份汇总。固定项目可查看每月总额柱状图，选中月份后联动账单和入住记录；缺失月份标为未记录。示例走势与实际账本隔离。

历史入住记录独立于分摊参与人；当前室友显示姓名，其他标识统一显示灰色匿名头像。退租人员仅登记人数，不收集姓名。已有水电燃气合并账单保留原金额与分类，不臆测拆分。

总额、个人应分摊、个人待付款分别展示。每笔保存不可变的分摊快照，记账时按整数分分配，付款记录不改变应分摊金额。新增表单实时预览；历史月份不可新增记录，已有账单的月份和过去月份均不可修改入住记录。

上述锁定为应用内约束：数据仍在 localStorage，不具备服务端防篡改能力或真实身份权限。生产使用需要服务端账本、身份校验及审计记录。

分摊方式支持全员平均、选择室友均摊、自定义每人金额。自定义金额合计必须与总额一致，采用整数分校验；规则和结果随账单冻结。账单页只展示金额，展开分摊方式可查看个人明细。

费用页顶部按当前室友展示待付款、待收款和已结清记录。当前室友为垫付人时，系统按分摊快照为每位未付款室友生成应收款；确认收款后转入已结清，不改变原始账单和分摊金额。

清洁值日采用周排班表：公共区域为行、周一至周日为列，任务卡按室友配色。支持切换周次、空白格直接排班、编辑负责人和状态，以及沿用本周安排生成下一周轮值。
